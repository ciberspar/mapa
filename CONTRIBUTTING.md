# Contribuir a ctOS // Global Official Sec-Grid

¡Gracias por tu interés en mejorar este proyecto! Toda ayuda es bienvenida para mantener la infraestructura y el rendimiento de la aplicación.

## ¿Cómo podés colaborar?
1. **Reportando errores:** Si encontrás algún fallo en el mapa, en el GPS o en las rutas, abrinos un [Bug Report](.github/ISSUE_TEMPLATE/bug_report.md).
2. **Sugiriendo mejoras:** Si tenés ideas para nuevas funciones (capas, estética, optimizaciones), creá un [Feature Request](.github/ISSUE_TEMPLATE/feature_request.md).
3. **Enviando código (Pull Requests):**
   * Hacé un Fork del repositorio.
   * Creá una nueva rama para tu función (`git checkout -b feature/nueva-funcion`).
   * Hacé commit de tus cambios (`git commit -m 'Agregada nueva función'`).
   * Subí la rama (`git push origin feature/nueva-funcion`).
   * Abrí un Pull Request explicando tus cambios.

## Estándares de Código
* Mantené la estética y paleta de colores ciberpunk.
* Asegurate de que los archivos principales sigan optimizados para mantener un alto rendimiento en PageSpeed.
