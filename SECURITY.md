# Política de Seguridad

## Versiones Soportadas

| Versión | Soportada          |
| ------- | ------------------ |
| 1.x     | ✅ Sí              |

## Reportar una Vulnerabilidad
Si encontrás algún problema de seguridad relacionado con la exposición de datos, fallos en la API de Overpass/Nominatim o problemas en el Service Worker, por favor reportalo de forma responsable abriendo una incidencia (*Issue*) en el repositorio o mediante los canales de contacto del mantenedor. 

Agradecemos la colaboración de la comunidad para mantener la red segura.
